# Tarevo — анализ требований

Учебный репозиторий для выполнения лабораторных работ по дисциплине «РиАТкПО».

Репозиторий содержит аналитическую документацию по проекту Tarevo на момент выполнения работ. Он не является репозиторием исходного кода или официальной производственной документацией продукта.

## Автор

- Родионов Родион Дмитриевич

Работа выполняется индивидуально.

## Кейс

Tarevo — мобильное приложение для учёта вещей, чеков, гарантий и истории эксплуатации бытовой техники.

## Структура репозитория

- `lab1/variants/Tarevo/case_concept.md` — концепция и границы кейса;
- `lab1/variants/Tarevo/RTM.md` — матрица трассировки требований;
- `lab1/variants/Tarevo/review_log.md` — журнал проверки и исправлений;
- `lab1/variants/Tarevo/export/` — экспортированная PDF-версия;
- `archive/research_materials/` — перечень использованных материалов.
